Verify an export offline.

Download the verifier, public key and exports into the same folder. The verifier requires Python and the cryptography package. The local signature proves integrity relative to this key; it is not sponsor attestation.

  • Signing public key
  • Authentic recorded export

python -m pip install cryptography
python veeriq_verify.py valid-live-recovery.json --public-key operator-public-key.pem
python veeriq_verify.py tampered-live-recovery.json --public-key operator-public-key.pem

The authentic export should pass. The deliberately tampered copy should fail.
