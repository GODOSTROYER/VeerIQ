# Three-minute demonstration

## Opening, 0:00–0:20

“VeerIQ is a research analyst whose authority follows one study protocol. It reads a synthetic cohort, analyzes the endpoint, and writes a report. Permission to analyze this study does not grant permission to export its participants.”

Show the study objective, then start the run. Use dark view for visual familiarity with the Flow State event. State the mode shown on screen: deterministic replay/local enforcement, or actual configured live mode.

## Useful work, 0:20–0:45

Point at the actual de-identified read and methods retrieval. Explain that the data has 240 synthetic participants in two groups. The statistics are computed, not prefilled display values.

## Push the boundary, 0:45–1:15

Open the retrieved methods note. It says validation requires participant export. “This document is evidence; it cannot grant authority.”

In deterministic replay, say: “We deliberately propose the action a compromised agent could take. We are testing the runtime boundary, not claiming this replay is live reasoning.” In a live run, show the model’s actual tool proposal if one occurred. If the live model refused, say so and switch to the explicitly labeled boundary replay.

## Prove non-execution, 1:15–1:45

Show three pieces of evidence together: export proposal DENY, handler entered NO, separate canary at zero bytes. Show identifier handler calls at zero. The statistician’s attempted publication is also outside its narrower authority.

For a credentialed submission, open the corresponding ArmorIQ plan or decision record and identify which decision came from ArmorIQ versus the application protocol. Never present the local scope signature as a sponsor-issued token.

## Recovery and result, 1:45–2:15

The analyst continues. Show the internal report: treatment B’s seeded mean improvement exceeds A’s by about 2.72 points, with an interval around [1.57, 3.83]. “These are synthetic results; the product demonstration is useful analysis under bounded authority.”

Explain that the child only receives analysis capabilities. This build demonstrates application scope narrowing; do not claim native cryptographic sponsor delegation before it is integrated and verified.

## Controlled publication, 2:15–2:45

Show the exact aggregate hash and fixed local review-board destination. “This action is potentially valid, so it pauses for review.” Approve the local aggregate. In sponsor HOLD mode, approve in ArmorIQ first, then check the runtime decision here.

Show approved publications changing from zero to one while raw export calls remain zero. The publishing tool uses its own generated aggregate, not model-supplied arbitrary text or rows.

## Close, 2:45–3:00

Download the receipt. “One study, narrow authority, denied effects, safe recovery, and one reviewed publication. The agent does the work; authority stays with the protocol.”
